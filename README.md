### Python Dictionary

This is a simple python dictionary which runs in your browser. It allows for new functions and datasets to be added and tested in the browser.
I created this because I found a Jupyter notebook to be too clunky and take up too much space on the screen. This way I can easily search up the functions I want to use.

Features:
- Create and edit your own entries, including syntax and notes 
- Categorised entries 
- Add keywords to search with (e.g. 'average' returns 'np.mean()')
- Import your own datasets
- Run Python and import modules for code examples to truly show what each function does

How to Use:
1. Add files using the 'Data' button on top
2. Add an import code to import said files, and the pandas/NumPy modules using the 'Setup' button. You can also create your own smaller data frames or arrays here, and they are available across the dictionary.
3. Add new entries.
